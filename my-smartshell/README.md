# my-smartshell: тестовый баннер

Статическая страница: HTML и CSS, без серверной части и сборки.

Открыть: https://ant0llla.github.io/smartshell-landing/my-smartshell/

Баннер ведёт на существующую форму PoC. Метки yclid и UTM синтетические: этот переход не является доказательством оплаченного клика Директа. Доступность и обработка заявки зависят от отдельного сервиса формы.

Исходная страница подготовлена в Harness, чат «PoC-05: развертывание и безопасный откат». Для размещения в подпапке GitHub Pages путь к стилям сделан относительным. Docker, Caddy и серверный скрипт для этой страницы не нужны.
